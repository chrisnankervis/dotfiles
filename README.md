# Dotfiles

Personal configuration files for my development environment.

## Tracked configuration

- Zsh (`.zshrc`)
- Codex (`.codex/AGENTS.md`)
- Git (`.config/git/.gitignore`)
- Ghostty (`ghostty/ghostty.config`)
- Oh My Posh (`oh-my-posh/themes/catppuccin_mocha.omp.json`)
- VS Code (`vscode/settings.json`, `vscode/keybindings.json`)

Some configs use symlinks so the files can live in this repository while still appearing in the locations expected by each tool.
